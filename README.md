# NOVA AI

### Your Intelligent AI Companion for Windows & Android

NOVA AI is an intelligent personal assistant designed to help users interact with technology through natural voice and text conversations.

The project aims to combine artificial intelligence, automation, memory, and natural language understanding into a modular and scalable personal assistant.

## Project Goals

NOVA AI is being designed to:

- Support Windows and future Android integration
- Understand English, Hindi, and Hinglish
- Support both voice and text interaction
- Understand context and remember conversations
- Execute commands and automate tasks
- Open applications and websites
- Search files and interact with the operating system
- Manage reminders and workflows
- Support modular plugins
- Provide permission-based and secure automation
- Support offline capabilities whenever possible
- Integrate local and cloud AI models

## Technology Stack

- **Language:** Python
- **Desktop UI:** PySide6
- **Database:** SQLite
- **Speech-to-Text:** Whisper
- **Text-to-Speech:** Piper
- **Wake Word Detection:** OpenWakeWord
- **Windows Automation:** pywin32, pyautogui, psutil
- **AI Architecture:** Hybrid Local + Cloud Models
